# ⚡ Consumo de Energia

## 📌 Objetivo
Este projeto tem o objetivo de calcular o **consumo mensal de energia** de um aparelho e calcular o **custo em reais**, considerando um valor fixo de R$ 0,75 por kWh.

## 🖥️ Linguagem Utilizada
- Python 🐍

## 🔢 Fórmula Utilizada
Foi utilizado a linguagem Python nesse exercício<br>
\[consumoMensal = (potencia * tempo * 30) / 1000\]
