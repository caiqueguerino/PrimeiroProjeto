# 📉 Porcentagem de desconto

## 📌 Objetivo

Este simples projeto tem como objetivo calcular o valor da compra e liberar o deesconto

## 💻 Liguagem de Programação

Foi utilizado a linguagem pyhton nesse projeto

## ▶️ Como Executar

- Abra o arquivo e digite o valor total da compra realizada
- No final o sistema irá retornar com a porcentagem de desconto e com o valor total ja descontado
